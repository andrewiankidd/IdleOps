# spkbak

Windows-only CLI for text-to-speech. Speaks text aloud through speakers or saves to WAV file using the built-in Windows TTS engine.

- **Docs**: [docs/spkbak/](../../docs/spkbak/README.md)
- **Build**: `dotnet build src/spkbak/spkbak.csproj`
- **Test**: `dotnet test src/spkbak.Tests/spkbak.Tests.csproj`
- **Dependencies**: System.Windows.Extensions
- **TFM**: `net10.0-windows10.0.22621.0` (WinRT SpeechSynthesis)
- **Platforms**: Windows 10/11
