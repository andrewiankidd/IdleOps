# scrcap

Windows-only CLI that captures a screenshot of a window and saves it to file. Supports PNG, JPEG, BMP, GIF, TIFF.

- **Docs**: [docs/scrcap/](../../docs/scrcap/README.md)
- **Build**: `dotnet build src/scrcap/scrcap.csproj`
- **Test**: `dotnet test src/scrcap.Tests/scrcap.Tests.csproj`
- **Dependencies**: shared (WindowCapture, WindowMatcher)
- **Platforms**: Windows only
